# 音频下载与音源接入指南

“音频下载”支持 LX Music 自定义 JS 音源，以及用户有权使用的自建、
购买或开放授权 REST 曲库。

## 添加 LX JS 音源

1. 打开“设置 → 音源管理”。
2. 将一个或多个 `.js` 音源文件拖进虚线框；也可以点击虚线框或
   “添加 JS 音源”按钮选择文件。
3. Echovault 会校验脚本，并把脚本支持的酷我、酷狗、QQ、网易云、咪咕
   等平台拆成独立音源。
4. 保存设置，回到左侧“音频下载”，选择平台后搜索。

JS 音源在短生命周期的独立兼容进程中运行；脚本无法直接调用 Echovault
主界面对象。请仍只导入来源可信、且你有权使用的音源文件。

## 添加 REST 音源

点击“添加 REST 音源”填写接口地址和路径模板，或使用“导入 REST JSON”。

接口地址必须使用 HTTPS。本机自托管服务可以使用
`http://localhost` 或 `http://127.0.0.1`。

## 配置示例

```json
{
  "schema_version": 1,
  "id": "licensed-catalog",
  "name": "我的授权曲库",
  "base_url": "https://catalog.example.com",
  "search_path": "/search?q={query}",
  "resolve_path": "/tracks/{id}?quality={quality}",
  "qualities": ["128k", "320k", "flac"],
  "headers": {
    "Authorization": "Bearer your-token"
  },
  "terms_url": "https://catalog.example.com/terms",
  "authorized": true,
  "enabled": true
}
```

## 搜索响应

```json
{
  "tracks": [
    {
      "id": "track-42",
      "title": "歌曲名",
      "artist": "歌手",
      "album": "专辑",
      "duration": "04:12",
      "qualities": ["320k", "flac"]
    }
  ]
}
```

搜索结果也可以直接提供 `download_url`，或按音质提供 `urls`：

```json
{
  "id": "track-42",
  "title": "歌曲名",
  "urls": {
    "320k": "https://cdn.example.com/track-42.mp3",
    "flac": "https://cdn.example.com/track-42.flac"
  }
}
```

## 解析响应

没有直接下载地址时，软件请求 `resolve_path`：

```json
{
  "url": "https://cdn.example.com/track-42.flac",
  "headers": {
    "Referer": "https://catalog.example.com/"
  }
}
```

下载文件自动使用“歌手 - 歌名”命名。目标文件已存在时会生成 `_2`、`_3`
等新文件，不覆盖旧文件；下载完成后目录会加入音乐素材库。
